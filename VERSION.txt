===========================================================================
*** THIS ROUND CHANGES server.js — THAT'S NEW, READ THIS CAREFULLY ***
===========================================================================
Every round so far has only ever touched files inside "public". This is
the first round in a long while to change server.js, which lives at the
TOP of this motionquest-deploy folder, next to "public" — not inside it.

That means the usual "just drag the public folder to GitHub" step is NOT
enough this time. You need to drag BOTH:
  - the "public" folder
  - the "server.js" file
onto https://github.com/Don7888/motion-run/upload/main in the same drop.
(You can select both of them together in Explorer — click "public", then
Ctrl+click "server.js" — and drag them in one go. Don't drag VERSION.txt
or the outer "motionquest-deploy" folder itself.)

If server.js doesn't go up along with everything else, the game will
still look and play the same, but the new reconnect/recovery behavior
below won't actually be live — the site would be running the OLD
server.js underneath the NEW public files, which would be a broken
mismatch. So please double check both are included before you upload.

===========================================================================
WHAT'S NEW THIS ROUND
===========================================================================
You: "Implement all seven items: session/reconnect foundation, TV/phone
recovery UI, setup feedback and safety copy, recalibration and remembered
setup, developer mode, then the Playwright coverage."

- If a phone or the TV drops for a few seconds (Wi-Fi blip, app switch),
  it now quietly reconnects on its own and picks up exactly where it left
  off — no lost setup, no restart. A calm "reconnecting" message shows
  during this; a manual retry button only appears if it can't recover on
  its own.
- If a session genuinely expires, both sides say so clearly: the TV shows
  a brand new pairing code, the phone shows "the TV session ended — scan
  new code".
- The placement screen now has a one-line reminder to clear some space and
  turn up the lights.
- Calibration shows a clearer demo animation per move and a short flash of
  confirmation when each move registers.
- Returning players are offered "Use remembered setup" instead of
  recalibrating from scratch every time — always still redoable, and it
  safely falls back to full calibration if anything about the app has
  changed.
- A hidden `?dev=1` developer test mode exists for testing the game
  without a real phone — it's visually unmistakable as a test tool and is
  blocked from ever appearing on the real published site.

Full details, test results and the manual test checklist are in this
round's write-up (motionquest-round-2026-09-16-ux-upgrade-delivery.md).
